⚙ Google API 키 설정
구글독스 원고를 읽어오려면 Google Drive API 키가 필요합니다. 키는 이 브라우저에만 저장되며 외부로 전송되지 않습니다.
키 발급 방법 (최초 1회, 약 3분)
1. Google Cloud Console 접속 → 프로젝트 생성
2. "API 및 서비스" → 라이브러리에서 Google Drive API 사용 설정
3. "사용자 인증 정보" → API 키 만들기 → 복사해서 여기에 붙여넣기
4. (권장) 키 제한: HTTP 리퍼러에 배포 도메인 등록, API 제한은 Drive API만

※ 검수할 문서는 "링크가 있는 모든 사용자"(뷰어 또는 편집자)로 공유돼 있어야 하며, 구글독스 문서와 워드(.docx) 파일을 모두 지원합니다.
